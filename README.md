## 🚀 Featured projects

### 🤖 AI & Agents
- **Macro RAG Agent** — An agent built from scratch that ingests macro news, research reports and central bank speeches to generate reasoned hypotheses on asset moves. *Think: a junior macro analyst that never sleeps.*
- **RAG Pipeline** — End-to-end retrieval-augmented generation: chunking, embeddings, vector search and grounded answers.
- **MCP Agent** — Tool-using agent built on the Model Context Protocol, connecting an LLM to real-world actions.
- **Internship Tracker Agent** — Reads my Gmail, detects application updates and keeps a Google Sheets pipeline in sync automatically.
- **Life Tasks Agent** — Turns my Obsidian vault into Telegram reminders, self-hosted on a school server.
- **n8n Job Workflow** — Automated LinkedIn job sourcing and application flow.

### 📈 Quant Finance
- **ML Algo Trading for Prop Firms** — Machine-learning swing strategies designed for funded-account rules (drawdown limits, risk per trade), with a human kept in the loop.
- **SBF 120 Challenge** — Backtesting pipeline and strategy search for a €100k simulated portfolio on French equities.

### 🔬 Data Science & Research
- **Mars Volcano Detection** — Statistical learning on HOG descriptors to spot volcanoes in Martian surface images. 🪐
- **PCA on the Tennessee Eastman Process** — Fault detection on a reference industrial chemical process via dimensionality reduction.
- **Fruit Fly Brain Simulation (FlyWire)** — Simulating neural activity on the real *Drosophila* connectome. 🪰🧠

### 🛠️ Products
- **Bike Fit** — Computer-vision app that analyzes a cyclist's posture from video and recommends bike adjustments.
- **SAE Web App** — Team project: Vue.js + Node.js/Express + SQL, fully Dockerized.
